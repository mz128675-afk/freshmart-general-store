# FreshMart — General Store Template

A general-store e-commerce website template built with HTML, CSS and JavaScript. An extra template project (not Project #7 in the portfolio queue).

## Features

- 6 categories (Vegetables, Fruits, Dairy & Eggs, Bakery, Pantry, Beverages) and 10 sample products with photos, prices in Rs, ratings and discount badges
- Live search, category filters and sorting
- Wishlist and a working cart drawer with quantity steppers and a free-delivery progress bar
- Weekend Deals banner with a live countdown and code WEEKEND30 (30% off)
- Full checkout flow — form, payment choice, order confirmation with order number and downloadable receipt
- Light/dark mode, responsive on mobile and desktop

## Live demo

https://mz128675-afk.github.io/freshmart-general-store/

## How to run

Open index.html in a browser, or serve the folder with any static server. No build step, no backend.
